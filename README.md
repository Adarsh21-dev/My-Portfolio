### 🛠️ Tech Stack
This project uses a lightweight yet powerful stack to ensure responsiveness and speed:
* **Frontend**: HTML5, CSS3, Font-awesome
* **Logic**: Vanilla JavaScript
* **Deployment**: Hosted on Render / GitHub Pages

### ✨ Key Features
* **Mobile-First Design**: Optimized for a perfect experience on Android/iOS devices.
* **Project Gallery**: Highlights my work in Kotlin, Jetpack Compose, and Python.
* **One-Click Connect**: Integrated links to LinkedIn, GitHub, and Email.
* **MIT Licensed**: Open for the community to learn and fork.
